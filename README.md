# ✈️ Optimal Flight Route Finder

A smart flight route planning system that helps users find the most efficient routes across 50,000+ U.S. flights, using **Dijkstra’s Algorithm** and a **Multilayer Perceptron (MLP)**.  
Built with **Django** (backend), **HTML/CSS/JavaScript** (frontend).

> Finding the most efficient flight route between cities is challenging due to factors like layovers, duration, and cost.  
> Our system aims to simplify this by offering optimized routes based on user preferences.

---

## 🚀 Project Overview

- Identify optimal flight paths based on:
  - **Minimum Cost**
  - **Minimum Time**
  - **Balanced Option** (cost & time trade-off)
- **Dijkstra’s algorithm** is used for shortest path computation.
- **MLP (Multilayer Perceptron)** improves route recommendations by learning from historical flight data.

---

## 🔧 Tech Stack

- **Backend:** Django
- **Frontend:** HTML, CSS, JavaScript, Leaflet API maps for flights routes
- **Algorithms:** Dijkstra’s Algorithm, Multilayer Perceptron (MLP)
- **Database:** Flight data from 50,000+ U.S. flights

---

## ⚙️ Key Features

- 🔍 **Optimized Pathfinding:** Efficient route computation using Dijkstra’s algorithm.
- 💡 **Custom Weighting:** Search by cost, time, or a smart balance of both.
- 🛫 **User Input System:** Enter source & destination cities with refined filters.
- 📊 **Scalable System:** Built to handle large datasets and deliver quick responses.
